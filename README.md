# Online Quiz Management System

## 1. Introduction
The Online Quiz Management System is a web-based application designed to conduct quizzes online. It allows students to attend quizzes and view their results. It also helps administrators manage quizzes and questions easily.

## 2. Objectives
- To conduct quizzes through an online platform.
- To allow students to participate in quizzes.
- To provide automatic score calculation.
- To reduce manual work in evaluating answers.
- To manage quiz questions efficiently.

## 3. Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js
- **Framework:** Express.js
- **Version Control:** Git and GitHub
- **CI/CD:** Azure DevOps Pipelines

## 4. Main Features
- Student quiz participation.
- Display of quiz questions.
- Answer
